# ApertusText Studio

A lightweight, open-source text processing and summarization utility powered by the Apertus large language model. Designed for efficient, sovereign, and private text comprehension.

## Features
- **Fast Summarization**: Quickly condenses long blocks of text into clean, structured summaries using Apertus LLM.
- **Privacy First**: Built with an emphasis on open-weight models and data sovereignty.
- **Lightweight Pipeline**: Clean Python architecture designed for real-world utility without bloat.

## Built With
- **Python**
- **Apertus LLM**
- **Open-Source AI Principles**

## Project Structure
- `app.py`: Core logic and integration pipeline with the Apertus model.
- `README.md`: Project documentation and architecture overview.
